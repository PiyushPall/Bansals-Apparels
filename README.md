## ✨ Overview

**Bansals Apparel** is a modern, responsive, and high-converting retail web storefront crafted for a premier family clothing store in **Bhajanpura Main Market, Northeast Delhi**. 

Designed with an editorial Indian heritage aesthetic (`#73030D` Crimson, `#732F3B` Plum, and `#FFF9F5` Warm Ivory), the application bridges online catalog discovery with in-store retail footfall—enabling shoppers to browse seasonal collections, inspect multi-angle product photography, save favorites to a persistent wishlist, build an inquiry bag, and verify live size/shade availability directly with store staff via WhatsApp.

## 🎯 Key Features

### 1. Storefront & Navigation Experience
- **Live Store Status Bar (`TopBar`):** Real-time *"Open Today"* indicator with store timings, landmark references, one-tap phone dialing (`tel:`), and instant Google Maps directions.
- **Dual-Tier Editorial Header (`Navbar`):** Custom botanical circular crest monogram with `Cinzel` serif branding, department tabs, instant catalog search modal, and slide-over drawers.
- **Panoramic Hero Slider (`HeroSlider`):** Auto-playing 3-photo montage banner showcasing seasonal wedding & festive collections with pause-on-hover and smooth `motion` transitions.

### 2. Interactive Catalog & Product Discovery
- **Dual-Angle Hover Slide Cards (`ProductCard`):** Hovering over any product card smoothly slides the primary photo out while revealing a secondary angle/detail shot.
- **Rich Quick-View Modal (`QuickInquiryModal`):**
  - Multi-photo interactive gallery with thumbnail strip and navigation controls.
  - Interactive **Size Selector** (`S`, `M`, `L`, `XL`, `XXL`, age ranges) and **Shade/Color Picker**.
  - Detailed fabric composition and complimentary in-house alteration notes.
  - Dynamic WhatsApp link generator that pre-fills the exact product title, category, selected size, and color.

### 3. Persistent Client-Side Shopping Tools
- **Saved Favorites (Wishlist) & Inquiry Bag (`StoreContext`):** Powered by React Context API and persisted in `localStorage` (`bansals_wishlist` & `bansals_inquiry_bag`).
- **One-Click Bulk WhatsApp Inquiry:** Send an entire wishlist or inquiry bag to the store's WhatsApp desk in a single formatted message to reserve outfits for in-store trial.

### 4. Four Curated Store Departments
| Department | Highlights |
| :--- | :--- |
| **Women's Ethnic & Bridal** | Bridal Zari Lehengas, Gotta Patti Velvet Kurtis, Chanderi Suits, Everyday Mulmul Cotton, Fusion Co-ords |
| **Men's Casual & Festive** | European Flax Linen Shirts, Slub Cotton Kurta Sets, Textured Nehru/Modi Jackets, Stretch Denim, Formals |
| **Newborn & Kids (0–14 Yrs)** | Age-segmented filters (`0–2 Yrs`, `Toddlers 2–5 Yrs`, `Pre-teens 6–14 Yrs`), 100% Bio-Wash Cotton Kits |
| **Cosmetics & Accessories** | Velvet Bridal Chuda Sets, Kundan Chokers, Banarasi Zari Potli Bags, Scalloped Organza Dupattas |

### 5. Local Trust & Visit Guide
- **Verified Google Reviews (`ReviewsSection`):** Highlights the store's `4.0★` rating (140+ local reviews) and key retail pillars.
- **Interactive Store Hub (`ContactView`):** Embedded Google Map, Metro transit guide (Shastri Park Red Line & Maujpur-Babarpur Pink Line), parking tips, and custom department inquiry form.

## ⚡ Getting Started

Follow these steps to set up and run the project locally on your machine.

### Prerequisites

- **Node.js** `v18.0.0` or higher
- **npm** `v9+` or **bun**

### Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd bansals-apparel
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables (optional):**
   ```bash
   cp .env.example .env
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:3000`.

## 🔍 SEO & Local Business Schema

This project is engineered for local search visibility in **Bhajanpura, Tukhmirpur, Yamuna Vihar, and Northeast Delhi**:
- **Structured Data (`JSON-LD`):** Embedded `ClothingStore` Schema.org markup in `index.html` with geo-coordinates (`28.6967, 77.2652`), opening hours, price range, aggregate ratings, and store departments.
- **Dynamic Page Titles:** Automatically updates `document.title` as users switch between Women's, Men's, Kids, Cosmetics, and Store Visit views.
- **Semantic Image Alt Tags:** Every catalog item includes descriptive local-SEO `altText`.
